At a glance

Two games in one loop: short matches and a home players keep for months.

Core Duel

1v1, 60–90 seconds. Shoot a glowing Core into the rival’s Reactor. No health, no damage: pure skill.

Underground base

Dig floor by floor, run rooms, send expeditions, rescue survivors. Fallout Shelter–style depth.

Growing roster

12 survivors at launch, more every season. Each is a base worker and a duelist.

Cross-platform PvP

Android vs iPhone online, quick match and room codes, built on Photon Fusion 2.

Fair monetization

Cosmetics, Season Pass, new gear, time skips, opt-in ads. Money never buys victory.

Live-ops ready

Accounts and cloud save, leaderboard, shop, seasons, daily gifts, analytics.
